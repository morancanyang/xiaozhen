# 陶里汇 · 商城综合体

双击 **商城综合体.html** 即可离线打开。Three.js、程序化材质、图形界面及抗锯齿查找纹理全部内嵌，不需联网。

本作品是为千人小镇设计的原创商业建筑方案。地块为 **112 × 112 m**，六层退台，最高构件约 **31.175 m**。单位为米，Y 轴向上，原点在地块完成面中心。地下薄基础最低约 −0.24 m。

## 浏览与导出

- 左键拖拽旋转，右键或 Shift＋拖拽平移，滚轮缩放。
- 手机单指旋转、双指缩放和平移。竖屏总览会自动调整距离。
- 上方提供总览、入口、退台、中庭、屋顶五个视角。
- 右侧切换午后／黄昏／夜景，开关访客、风、灯光、水景、云层和摄影景深。
- 可暂停动态、调节速度、选择画质。自动画质在持续低帧率时降低材质开销。
- 左侧支持复位、缩放、地块边界及摄影模式。空格暂停，H 复位，Esc 退出摄影模式。
- 底部可导出 GLB 和 PNG。4K 为 3840 × 2160；8K 为 7680 × 4320，设备纹理尺寸与显存须支持。

包含行人行走和停留、接近开启的自动门、循环扶梯、树冠与布旗摆动、喷泉、缓慢轮播的电子屏和动态云层。建筑结构保持稳定。微缩人物和树木采用简化造型。

## 接入千人小镇

本次交付独立商城模块，现有城市街区源码和部署未修改。

```js
import { createMallComplex } from './mall-module.mjs';

const mall = createMallComplex({
  THREE, // 宿主已有的 THREE 命名空间
  footprint: 112,
  quality: 'high',
  seed: 2026,
  includeLandscape: true
});

mall.model.position.set(parcelX, groundY, parcelZ);
mall.model.rotation.y = rotationRadians;
scene.add(mall.model);

// 放进宿主已有的帧循环，不新增 renderer、camera 或 requestAnimationFrame。
mall.update(deltaSeconds, {
  paused: false,
  nightFactor: 0, // 0 午后，1 夜景，可连续变化
  people: true,
  wind: true,
  lights: true,
  water: true,
  cameraDistance: camera.position.distanceTo(mall.model.position)
});

mall.setQuality('medium'); // high / medium / low
mall.setTimeOfDay('sunset'); // 或 afternoon、night、0～1 数值
const worldBounds = mall.getBounds();

// 删除时释放本模块拥有的资源，保留宿主环境和渲染器。
mall.dispose();
```

如果 update 中持续传入 nightFactor，它优先于 setTimeOfDay 的设置。可选 time 是外部统一模拟时钟；不传时由 dt 推进。暂停期间不推进模型时间。隐藏访客时停止其行走计算。

footprint 会将整个模块等比缩放，包含建筑高度。includeLandscape=false 会去掉广场活动家具、室外访客、行道树与喷泉，保留基础地面和建筑自身退台景观。

模型工厂需运行于有 Canvas API 的浏览器中。正式接入推荐同一版本 Three.js；本交付用 0.180.0 验证。

接入演示请通过本地 HTTP 打开，以允许同源 iframe 访问：

## 开发与复现

源码位于 src。已有本项目依赖可直接运行；移至新环境时先 npm install。

```powershell
npm run check
npm run build
python tools/review.py
```

tools/review.py 用本机 Edge 无头浏览器检查粗模和五个精细视角，导出同一模型的 outputs/scene.json。运行 python tools/verify.py 会验证离线页面、交互、导出、手机布局、宿主接入及资源释放；测试自身创建临时本地 HTTP 服务并在完成后关闭。

本地 Blender MCP 桥接位于 tools/blender_mcp.py，使用 stdio 协议，客户端为 tools/run_mcp.py。调用 blender_inspect、blender_render_landmark、blender_render_status；每次从同一份 Three.js 场景 JSON 导入建模。Blender 使用独立后台进程和 factory startup，输出仅写入本文件夹。

```powershell
& '..\city-atlas\.venv\Scripts\python.exe' tools/run_mcp.py
```

复现需要 Python mcp、pydantic，以及本机 Blender；可通过 CITY_BLENDER_EXE 指定其他 Blender 路径。Cycles 优先选择 OPTIX GPU，无可用设备时回退 CPU。

## 效果范围与许可

浏览器使用实时 PBR、阴影、透射近似、泛光、SMAA 及可选景深；Blender 使用原生 Cycles 光线追踪。二者共享建筑几何，光照和玻璃表现按各自渲染器设置。

建筑、标识和程序化纹理为本项目生成。Three.js 为 MIT 许可，详见 THREE-LICENSE.txt。

Three.js 技术参考：[物理材质](https://threejs.org/docs/pages/MeshPhysicalMaterial.html)、[OrbitControls](https://threejs.org/docs/pages/OrbitControls.html)。
