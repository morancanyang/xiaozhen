# 晴空游乐园 · SKYDAY

独立的 112×112 米微缩游乐场。未修改千人小镇现有地块。入口朝 +Z，米制、Y 轴向上，地面中心为原点。

## 使用

双击 `晴空游乐园.html`，无需联网、无需安装依赖。左键拖拽旋转，右键或 Shift 拖拽平移，滚轮缩放；触屏支持单指旋转和双指缩放、平移。H 复位，空格暂停，Esc 退出摄影模式。

右下设置面板默认折叠。展开后可切换白天、黄昏和夜景，独立启停摩天轮、过山车、木马和海盗船，并设置风动、灯光、景深、运行速度及画质。停止设施会平滑减速；全局暂停立即冻结动态。海盗船停机会缓慢回到静止角度。

全园无人，列车与座舱均为空载。摩天轮十二个座舱独立保持竖直，轮圈直径约 34 米；最高构件约 39.18 米。过山车为闭合双轨，四节车厢分别按弧长匹配轨道位置及倾斜姿态，回站减速。木马平台旋转与马匹升降具有不同相位。海盗船围绕上部轴摆动。滑梯具有开放滑道、实体侧壁、阶梯与扶手。

## 交付

- `晴空游乐园.html`：完整离线查看器。
- `晴空游乐园.glb`：导出时刻的静态模型快照，嵌入纹理。
- `晴空游乐园.blend`：从同一份网页几何导入的可编辑 Blender 工程，按设施与材质组织集合；摄影环境独立。
- `amusement-park-module.mjs`：宿主 THREE 注入式工厂。
- `town-integration.example.mjs`：千人小镇接入示例。
- `接入演示.html`：同源 HTTP 接入演示，使用 `python -m http.server 5183 --bind 127.0.0.1` 后访问。
- `outputs/blender-*.png`：Cycles 物理渲染，包括 3840×2880 总览、摩天轮、过山车、旋转木马、海盗船和夜景。
- `outputs/browser-4k.png`：网页直接导出的 3840×2160 PNG。
- `outputs/verification.json`：32 项验收和 64 秒运动遍历记录。

HTML 和模型模块包含程序动画。GLB、Blender 工程保存导出时的姿态，不包含可运行的完整程序机构。

## 接入

```js
import {createAmusementPark} from './amusement-park-module.mjs';
const park=createAmusementPark({THREE,footprint:112,quality:'high',includeLandscape:true});
park.model.position.set(block.x, .36, block.z);
scene.add(park.model);
// 由宿主既有的动画循环驱动；speed 在本接口内乘入，只传入一次速度。
park.update(deltaTime,{
  paused:false,speed:1,wind:true,windStrength:.6,lights:true,nightFactor:0,
  rides:{ferrisWheel:true,rollerCoaster:true,carousel:true,pirateShip:true}
});
park.setQuality('medium'); // high / medium / low
park.setTimeOfDay('night'); // morning / sunset / night，或者 0–1
const current=park.getBounds();
const reserved=park.getMotionBounds();
park.dispose(); // 可重复调用，不释放宿主资源
```

`parts` 包含 landscape、ferrisWheel、rollerCoaster、carousel、pirateShip、slide、detail、lighting。`metadata` 包含地块、单位和模型信息。`getBounds()` 返回变换后的当前构件边界，逐个处理旋转中的实例，避免轮圈整体包围盒旋转后产生错误的地下边界。`getMotionBounds()` 返回保守的完整运动预留范围，包含边界浮点容差；它不是实测几何的紧包围盒。

工厂不创建摄像机、渲染器或动画循环，不修改宿主环境。局部灯光属于园区，随模型一起卸载。`includeLandscape:false` 可隐藏独立场地和入口景观，保留设施本身。`footprint` 最小 56 米，对模型等比缩放。

同源 iframe 可打开 `晴空游乐园.html?mode=asset`，读取 `contentWindow.QianrenLandmarks.createAmusementPark`。此模式不创建查看器或画布。

## 验证与复现

`src/model.js` 为模型，`src/app.js` 为查看器，`src/shell.html` 和 `src/style.css` 为界面。执行 `npm install` 后运行 `node build.cjs` 重新构建；当前脚本也可使用旁边已有的千人小镇依赖。

安装 `tools/requirements.txt` 后执行 `python tools/verify.py`。需要 Microsoft Edge。验收检查完整 64 秒设施运动、闭合轨道、列车姿态、座舱竖直、地块边界、启停、灯光、离线运行、导出、手机布局和宿主接口。边界检查不等于全场任意三角面的精确碰撞求解。

执行 `uv run --with "mcp>=1.20,<2" python tools/run_blender_mcp.py`，通过真实 stdio MCP 会话调用本地 Blender，导入 `outputs/scene.json`，保存工程并渲染。默认 Blender 路径为 `C:\Program Files\Blender Foundation\Blender 5.2\blender.exe`，可通过 `CITY_BLENDER_EXE` 修改。

实际渲染器为 Blender Cycles，Octane 用作视觉参考。Three.js MIT 许可证见 `THREE-LICENSE.txt`。
