# 大学主教学楼 · 知行校园

这是独立模型交付，未替换或修改千人小镇的任何城市地块。

## 直接查看

双击 `大学主教学楼.html`。这是完整离线文件，包含 Three.js、模型、字体回退、程序生成纹理和查看器，无需安装 Node.js，无需联网。

左键拖拽旋转、右键或 Shift 拖拽平移、滚轮缩放。触屏支持单指旋转和双指缩放、平移。H 复位，空格暂停，Esc 退出摄影模式。右下角“此刻，在校园”展开风力、时间、画质与动态设置。默认晨光，另有黄昏、夜景。

主楼七层、侧翼五层，建筑高度约 28.53 米；地块 112×112 米，模型边界约 110×110 米。旗台中心与入口中轴线对齐。一面五星红旗、十面小红旗，旗帜通过真实网格变形实现风动，固定侧不移动。模型还包含混凝土分缝、凹入式窗洞、窗框、窗台、教室窗帘、入口雨棚、台阶、无障碍坡道、铺装板缝、草坪、树木与路灯。

`?coarse=1` 可切换为体块粗模，用于比较建模阶段。查看器不是测绘 BIM。

## 文件

- `大学主教学楼.html`：可交互离线模型。
- `大学主教学楼.glb`：导出时刻的静态模型，嵌入纹理和分组。
- `大学主教学楼.blend`：Blender 可编辑工程，按 architecture、landscape、detail、flags、lighting 分组；摄影环境为单独集合。
- `university-module.mjs`：独立模型工厂，接收宿主的 THREE。
- `town-integration.example.mjs`：千人小镇接入包装示例，不会自动删除原地块。
- `接入演示.html`：同源 HTTP 环境下演示宿主接入。使用 `python -m http.server 5182 --bind 127.0.0.1` 后访问该文件。
- `outputs/polished-*.png`：六张精修版 Cycles 物理渲染图，总览为 3840×2880；包括正面、入口、旗面、窗框和旗台近景。
- `outputs/final-*.png`：网页交互检查截图。
- `outputs/browser-4k.png`：实际导出的 3840×2160 PNG。
- `outputs/verification.json`：37 项浏览器检查及本机运行统计。

## 模型接口

```js
import {createUniversityCampus} from './university-module.mjs';

const campus=createUniversityCampus({
  THREE, footprint:112, quality:'high', includeLandscape:true
});
campus.model.position.set(block.x, .3, block.z);
scene.add(campus.model);

// 在宿主原有动画循环中调用，不另外建立 requestAnimationFrame。
campus.update(deltaTime, {
  paused:false,
  wind:true,
  windStrength:.6, // 0–1
  flags:true,
  lights:true,
  nightFactor:0, // 0 为晨光，1 为夜景
  cameraDistance:180
});

campus.setQuality('medium'); // low / medium / high
campus.setTimeOfDay('night'); // morning / sunset / night 或 0–1
const bounds=campus.getBounds(); // 包含模型当前世界变换
// 卸载时调用；允许重复调用，不释放宿主环境贴图。
campus.dispose();
```

地块原点在地面中心，单位米，Y 轴向上，入口朝 +Z。`footprint` 最小 56 米，对全场地等比缩放。工厂只创建模型与自有资源，不创建相机、渲染器或全局光源。`metadata` 包含尺寸、层数及地块信息；`parts` 分别提供建筑、景观、细节、旗帜及灯光网格。`setTimeOfDay` 调整模型灯光材质，宿主负责天空和太阳；若每帧提供 `nightFactor`，该值优先生效。

也可在同源 iframe 中打开 `大学主教学楼.html?mode=asset`，通过 `contentWindow.QianrenLandmarks.createUniversityCampus` 获取工厂；此模式不创建查看器、画布或动画循环。

交互动画由 HTML/JavaScript 驱动。GLB 和 Blender 工程保存旗面导出时的姿态，不包含完整程序风场。查看器支持截图尺寸选择；高分辨率截图能力受设备纹理尺寸和显存限制。

## 源码与复现

`src/model.js` 为模型源文件，`src/app.js` 为查看器，`src/style.css` 和 `src/shell.html` 为界面。`node build.cjs` 打包 HTML 和模型模块；首次使用独立目录需先 `npm install`。当前构建脚本同时兼容旁边已有的千人小镇依赖目录。

浏览器验收：安装 `tools/requirements.txt` 和可用的 Microsoft Edge，执行 `python tools/verify.py`。验收包含离线网络请求、边界、旗帜固定端、动态暂停、风力、昼夜、导出、实际触屏事件、减少动态偏好、宿主接入和资源释放。

本地 Blender MCP：`uv run --with "mcp>=1.20,<2" python tools/run_blender_mcp.py`。默认查找 `C:\Program Files\Blender Foundation\Blender 5.2\blender.exe`，可用 `CITY_BLENDER_EXE` 指定其他路径。它通过真实 stdio MCP 会话启动 Blender，导入 `outputs/scene.json` 的同一套网页几何和纹理，再保存工程并渲染六个视角。

实际渲染器是 Blender Cycles；Octane 是视觉参考，交付未声称使用 Octane。Three.js 的 MIT 许可证见 `THREE-LICENSE.txt`。

- 国旗增加双道包边缝线、旗绳和升旗连接孔，旗杆与路灯增加基座连接件。
- 草坪增加独立短草叶，树木增加分枝和细化叶簇，屋顶设备增加百叶和基础。
- Blender 中加入混凝土、石材微表面、边角光泽和布料绒光，并使用更清晰的晨光阴影与高清细节镜头。
