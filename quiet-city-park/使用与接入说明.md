# 森隐公园 · SENYIN

独立的 112×112 米森林公园模型。未替换千人小镇任何地块。米制，Y 轴向上，原点为地块中心。公园包含 62 株分枝乔木、细分叶簇、灌木、短草地、碎石环路、五处木质长椅、石质路灯、不规则湖盆、水面、浮叶与岸边植被，全场无人。

## 查看

双击 `森隐公园.html`，全部依赖和程序纹理均在单文件内，可离线运行。左键旋转，右键或 Shift 拖拽平移，滚轮缩放；触屏支持单指旋转与双指缩放、平移。H 复位，空格暂停，Esc 退出摄影模式。

右下角设置可展开，支持风动、水波、风力、云层、路灯、画质、速度和摄影景深；白天、黄昏和夜景平滑切换。顶端提供六个镜头。`?coarse=1` 为 30 株简化树木的粗建模视图。

湖泊中心为 (12,-5)，参考半径 17×12 米，岸线不规则。水位约 -0.35 米，湖底最低 -1.8 米；地块土层底部 -2.3 米。湖泊由真实地形凹陷形成，水面按连续波函数变形，浮叶随水面起伏。

## 文件

- `森隐公园.html`：可交互离线模型。
- `森隐公园.glb`：带纹理与地形顶点色的静态快照。
- `森隐公园.blend`：同一套 Three.js 几何导入的 Blender 工程，摄影环境独立集合。
- `quiet-park-module.mjs`：独立模型工厂。
- `town-integration.example.mjs`：宿主接入示例。
- `接入演示.html`：同源 HTTP 接入演示，可用 `python -m http.server 5185 --bind 127.0.0.1` 启动后查看。
- `outputs/blender-*.png`：六张 Cycles GPU 渲染，含 3840×2880 总览、林间小径、湖面、长椅、细节及夜景。
- `outputs/verification.json`：浏览器验证记录。
- `outputs/visible-progress.json`：Blender 可见窗口渲染进度。
- `outputs/blender-result.json`：实际渲染结果。

HTML 与模块包含程序风场、水面和浮叶动态。GLB、Blender 工程保存导出时的静态姿态。

## 接入接口

```js
import {createQuietCityPark} from './quiet-park-module.mjs';
const park=createQuietCityPark({THREE,footprint:112,quality:'high'});
park.model.position.set(block.x,0,block.z);
scene.add(park.model);
park.update(deltaTime,{
  paused:false,speed:1,wind:true,windStrength:.35,
  water:true,lights:true,nightFactor:0
});
park.setQuality('medium'); // high / medium / low
park.setTimeOfDay('night'); // morning / sunset / night 或 0–1
park.getBounds();
park.getMotionBounds();
park.dispose(); // 可重复调用，仅释放自身资源
```

`parts` 提供 terrain、water、paths、trees、shrubs、grass、benches、lighting、detail。`metadata` 包含地块信息、树木数量、湖泊参数及 `requiresGroundCut:true`。

接入城市时需要清除该地块原有地面与土层对湖盆的遮挡，不能直接把模型压在一块完整地面上。独立地形范围约 110×110 米，外缘可与城市人行道衔接。湖盆的完整土层深度需要保留。`footprint` 最小为 56 米，等比缩放整个模型。

工厂不创建相机、渲染器或动画循环，不修改宿主天空和环境贴图；局部路灯属于模型。云层由独立查看器实现，接入时复用宿主天空。地形、植被和湖泊共同构成公园主体，当前工厂不提供整体剥离景观的开关。

同源 iframe 可加载 `森隐公园.html?mode=asset`，读取 `contentWindow.QianrenLandmarks.createQuietCityPark`。此模式不创建查看器或动画循环。

## 构建与本机 Blender MCP

`src/model.js` 为模型，`src/app.js` 为查看器。安装 npm 依赖后执行 `node build.cjs` 生成单文件与模块；当前也支持旁边已有的千人小镇依赖。

安装 `tools/requirements.txt` 后执行 `python tools/verify.py`。需要 Microsoft Edge。

执行 `uv run --with "mcp>=1.20,<2" python tools/run_mcp.py`：先通过 MCP 后台准备同一套几何、材质和地形顶点色，再在新的 Blender 可见窗口中用异步界面渲染任务逐张输出图片。不会修改已经打开的其他 Blender 工程。默认查找 Blender 5.2，可通过 `CITY_BLENDER_EXE` 指定其他可执行文件。

实际使用 Blender Cycles，Octane 作为视觉参考。Three.js MIT 许可证见 `THREE-LICENSE.txt`。
